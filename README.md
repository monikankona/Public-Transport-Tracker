Smart Bus Transit System

Features:

1. Passenger Portal
- Live bus tracking on map (Leaflet.js)
- Search specific bus by registration number
- Journey planner with route visualization
- AI assistant for transport queries
- Weather updates
- Real-time date & time display

2. Admin / Driver Dashboard
- Driver authentication (Login/Register)
- Live GPS tracking of buses
- Start & end trip functionality
- Trip analytics (distance, duration)
- Network status monitoring


Tech Stack

- Frontend: HTML, CSS, JavaScript  
- Styling: Tailwind CSS  
- Maps: Leaflet.js  
- Backend / Database: Firebase Firestore  
- APIs Used:
  - OpenRouteService (Routing & Navigation)
  - WeatherAPI (Weather Data)
  - Gemini API (AI Assistant)
